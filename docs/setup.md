# Developer OS Setup

Welcome to the Developer OS. Follow these steps to deploy this profile to your GitHub account:

1. **Create Repository:** Create a new repository with the same name as your GitHub username (e.g., `your-username/your-username`).
2. **Copy Files:** Copy the contents of this `github-profile-os` directory into your new repository.
3. **Customize Variables:**
   - In `README.md`, find the GitHub Stats URLs: `https://github-readme-stats.vercel.app/api?username=your-username...` and replace `your-username` with your actual GitHub username.
   - Edit the files in the `/database/` folder to reflect your actual projects, skills, and roadmap.
4. **Commit & Push:** Commit these changes and push to your main branch. Your GitHub profile will instantly transform into the Developer OS.
